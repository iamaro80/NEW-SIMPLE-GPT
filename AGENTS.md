# Prototype UI Conventions

For data-grid CRUD views in this prototype:

- Order the page content as title, primary Add action, search/filter fields, then the grid.
- Apply filters as the user types or changes a selection. Do not add Search or Reset buttons unless the user explicitly requests them.
- Use plausible, domain-related mock data. Do not copy test/sample values from extracted legacy-system screenshots or notes.
- Keep existing pages unchanged unless the user asks to align them with a new convention.
